  -> hires/uses Engineer employee

  -> heartbeat dispatches a beat

  -> Dream loads tools, project skills, plugins, MCP allowlist, project memory, working memory, evaluator
  -> Engineer writes artifacts
  -> Dream result + Chorus verification land run/task state
  -> EventBus records run events for inspection
